# Make the Judge Smile

Entry for [Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d) on make.fun.

One line, at most 200 characters, about a small good thing that happened today. The house judge reads entries two at a time and keeps the one that makes it smile.

> The cat that usually ignores me waited at my gate this morning and walked me all the way to the corner, tail up.

## How it works

`main.ts` (Node 22, no dependencies) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates it first — 1–200 characters, not only whitespace, a single line — then reads it back and verifies it is byte-identical.

```sh
node main.ts
```
